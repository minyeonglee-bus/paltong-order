📋 인쇄 대기

    아이패드에서 🖨 누른 주문이 여기 쌓여요. 🖨 인쇄를 누르면 RawBT로 바로 나가요.

    프린터로 보내는 방법

    인쇄할 장 (관리자 화면 설정이 우선)

    최근 인쇄

    • 아직 없어요
    처음 설정 방법 (한 번만)
    1. 와이파이 프린터를 가게 와이파이에 연결하고, 프린터 IP 주소를 확인해요 (전원 켤 때 나오는 자가 테스트 종이, 또는 FEED 버튼 길게 누르기 → 종이에 적힌 IP, 예: 192.168.1.87)
    2. 이 안드로이드폰도 같은 와이파이에 연결해요
    3. Play 스토어에서 RawBT(ESC/POS thermal printer driver)와 Server for RawBT 앱을 설치해요
    4. RawBT 앱 → 설정 → 연결 방식 네트워크(LAN/Wi‑Fi) → 프린터 IP 입력, 포트 9100 → RawBT 안에서 테스트 인쇄가 나오는지 확인
    5. Server for RawBT 앱을 열고 켜두기 (배터리 최적화 '제외'로 설정하면 꺼지지 않아요)
    6. (자동을 쓰려면) 이 화면에서 ⚡ 자동 인쇄를 고르고 '테스트 인쇄' → 영수증이 나오면 끝!
      "로컬 네트워크 기기 접근" 허용 창이 뜨면 허용을 눌러주세요
    7. 자동이 안 되면 📋 목록에서 눌러서 인쇄를 고르세요. 아이패드에서 🖨 누른 주문이 목록에 뜨고(띵동 소리), 🖨 인쇄를 누르면 나와요
    8. 이 폰은 충전기에 꽂고 이 화면을 켜둔 채 두세요. 아이패드 관리자 화면 🖨 프린터 설정에서 📡 와이파이 프린터 (인쇄 스테이션)을 고르면 연결 끝
